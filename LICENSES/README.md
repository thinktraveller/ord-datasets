# License texts and boundaries

This directory records the license boundary used by this publication
workspace; it is not a blanket license for all files.

- [LICENSE-DATA](../LICENSE-DATA) is the exact CC BY-SA 4.0 text copied from
  the frozen ORD source release. It applies only to artifacts whose
  provenance/license-inventory.csv decision is
  license_confirmed_pending_sensitive_audit with audited license
  CC-BY-SA-4.0.
- [LICENSE-CODE](../LICENSE-CODE) is the exact Apache-2.0 text copied from the
  frozen ORD source release. It applies only to code artifacts whose
  provenance/license-inventory.csv decision is
  license_confirmed_pending_sensitive_audit with audited license Apache-2.0.
- [NOTICE](../NOTICE) states required attribution, modification disclosure,
  retention of notices, and the non-redistribution boundary for unresolved
  material.

The complete license evidence and every artifact-level decision are in
provenance/license-inventory.csv and reports/license-audit/. Unknown,
third-party, quarantined, excluded, superseded, or unverified workspace
artifacts remain outside the upload allowlist.
